# NAC Music Apps

Music apps for the **New Apostolic Church** – to the honour and glory of God.

| App | What it does | Price |
|---|---|---|
| **NAC Choir Rehearsal** | Practise every song with moving scores, your own part louder, the hymn books, rehearsal plans | Free |
| **NAC Music Hub** | Programmes, booklets, score books, choir, concerts, projection, workshops, congregation and newsletters | Unlock code |
| **NAC Programme Studio** | Service and concert programmes, hymn library, booklets, flyers, tickets, slides | Unlock code |
| **NAC Service Projector** | Hymn words, slides and videos on the projector | Unlock code |

## Use online or on a phone
Open **https://infinitytimetable.github.io/NAC-Music-Hub/**, choose an app, then *Add to Home screen*. After the first opening it works without internet.

## Install on a Windows PC
Download from the [Releases page](https://github.com/infinitytimetable/NAC-Music-Hub/releases/latest), unzip, and double-click **Install.bat**.
Already installed? Double-click **Update NAC apps** on the desktop.
